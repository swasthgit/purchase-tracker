# **App Name**: Purchase Tracker

## Core Features:

- User & Partner Selection: Allow users to select their ID and partner name from dropdown menus.
- Item Entry: Enable users to add purchased items, specifying clinic code, quantity, price, and item name via dropdown menus.
- Multiple Item Entry: Provide an 'Add Another Item' option for multiple item entries and a 'Duplicate' button for repeating entries.
- Language Translation: Integrate Google's built-in language translation for English and Hindi, and optionally other languages if the tool deems it necessary for an international user base.
- Data & File Recording: Capture and store user-uploaded images and files with their associated entries.
- Admin Page: Admin page to add or remove printer names and employee IDs.
- Bulk User ID Upload: Bulk upload option for adding user IDs from an Excel file.

## Style Guidelines:

- Primary color: Blue shades to represent trustworthiness and efficiency.
- Secondary color: Orange shades to represent energy and action.
- Background color: Light gray (#E0E0E0), offering a clean and neutral backdrop to ensure clarity.
- Accent color: A muted purple (#800080), strategically used for interactive elements.
- Clean and easily readable sans-serif fonts should be prioritized.
- Use minimalist icons for item categories and actions like 'add' or 'duplicate'.
- Maintain a clear and structured layout for ease of data entry and viewing.
- Employ subtle transitions and animations for adding items or duplicating entries.
