# Purchase Tracker

A comprehensive Next.js application for managing and tracking purchases with Firebase backend.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:9002](http://localhost:9002)

## 🔧 Configuration

1. Copy `.env.example` to `.env.local`
2. Add your Firebase credentials
3. Run `npm run dev`

## 📦 Tech Stack

- Next.js 15.3.5 (App Router)
- Firebase (Firestore + Storage)
- TypeScript
- Tailwind CSS + ShadCN UI
- React Hook Form + Zod
